# AI重构DevOps课程 · 竞赛记分牌评分规则

> **版本**：v2.0（2026-07-29 修订）
>
> 适用于 4 天训练营竞赛模式。

---

## 0. 总览

- **参赛小组数**：可配置，4 / 5 / 6 / 7 / 8 组（默认 6 组）
- **总分**：120 分
- **排名规则**：按各组总分从高到低实时排序

| 序号 | 评分项 | 满分 | 保底分 | 说明 |
| :-: | :--- | :-: | :-: | :--- |
| 1 | 开场展示分 | 5 | 3 | 团队介绍 + AI工具箱方案 |
| 2 | 演练成果分 | 54 | 36（9项×4） | 9个演练项目，每项满分6分，保底4分 |
| 3 | 阶段总结分 | 9 | 3（3次×1） | 4天共3次课前总结，每次满分3分，保底1分 |
| 4 | 出勤准时分 | 24 | 12 | 8次课 × 每次3分 |
| 5 | 课堂表现分 | 12 | 0 | 每组最多12次加分，每次1分 |
| 6 | 综合展示分 | 16 | 8 | 最终成果汇报（4天课程结束后） |
| | **合计** | **120** | **62** | |

计算公式：
```
总分 = 开场展示分 + Σ演练成果分(9项) + Σ阶段总结分(3次) + 出勤准时分 + 课堂表现分 + 综合展示分
```

---

## 1. 开场展示分（满分 5 / 保底 3）

- **评分内容**：团队介绍 + AI工具箱方案展示
- **打分标准**：

| 等级 | 分值 | 标准 |
| :--- | :-: | :--- |
| 🏆 优秀 | 5 | 团队介绍完整 + AI工具箱方案有创新亮点（如独特工具组合、有对比分析） |
| ✅ 良好 | 4 | 团队介绍完整 + AI工具箱方案完整、逻辑清晰 |
| 🔄 保底 | 3 | 团队介绍基本完整 |

- **扣分规则**：

| 情形 | 扣分 |
| :--- | :-: |
| 未准备团队介绍 | 扣至保底分（3分） |
| 无AI工具箱方案 | 扣1分 |
| 超时（超过规定展示时间） | 扣1分 |
| 仅1人上台，其他组员未参与 | 扣1分 |

---

## 2. 演练成果分（满分 54 / 保底 36）

- **规则**：9 项演练，每项满分 **6 分**，保底 **4 分**（基本做出来即可获得保底分）
- **评分维度**：每项演练从以下 3 个维度综合打分

| 维度 | 分值 | 说明 |
| :--- | :-: | :--- |
| 完成度 | 0~2 | 核心功能/内容是否完成，界面或逻辑能否跑通 |
| 正确性 | 0~2 | 成果是否准确，是否符合要求 |
| 质量与亮点 | 0~2 | 代码/文档质量、AI工具运用效果、创新点 |

> **保底分（4分）判断标准**：基本做出来——核心功能/内容完成，界面或逻辑可以跑通演示，即获得 4 分。

- **扣分规则**：

| 情形 | 扣分 |
| :--- | :-: |
| 核心功能未完成（无法演示主体内容） | ≤ 保底分（≤4分），根据完成度打 4~5 分 |
| 成果有明显错误 | 扣1分 |
| 完全未提交/未演示 | 0 分 |
| 与其他组雷同且无差异化 | 扣1分 |

---

## 3. 阶段总结分（满分 9 / 保底 3）

- **规则**：4 天课程共 **3 次**课前总结，每次满分 **3 分**，保底 **1 分**（有参与发言即可获得保底）
- **时间安排**：

| 序号 | 时间节点 | 满分 | 保底 |
| :--- | :--- | :-: | :-: |
| 第1次 | 第2天课前（回顾第1天） | 3 | 1 |
| 第2次 | 第3天课前（回顾第2天） | 3 | 1 |
| 第3次 | 第4天课前（回顾第3天） | 3 | 1 |

- **打分标准（每次）**：

| 等级 | 分值 | 标准 |
| :--- | :-: | :-: |
| 🏆 优秀 | 3 | PPT/白板总结到位，有数据支撑、有反思总结 |
| ✅ 良好 | 2 | 有总结，表达清晰，但缺少数据或反思 |
| 🔄 保底 | 1 | 有参与发言，内容基本准确 |

- **扣分规则**：

| 情形 | 扣分 |
| :--- | :-: |
| 未参与总结发言 | 0 分 |
| 总结内容与事实明显不符 | 扣至1分 |
| 超时 | 扣1分 |

---

## 4. 出勤准时分（满分 24 / 保底 12）

- **规则**：8 次课 × 每次 3 分（上午4次 + 下午4次）
- **每次出勤 3 分分配**：

| 要求 | 分值 |
| :--- | :-: |
| 准时到课 | 2 分 |
| 全程在课（无早退） | 1 分 |

- **扣分规则**：

| 情形 | 扣分 |
| :--- | :-: |
| 迟到（≤15分钟） | 扣1分/次（出勤分从3→2） |
| 迟到（>15分钟） | 扣2分/次（出勤分从3→1） |
| 早退 | 扣1分/次 |
| 请假（提前报备） | 扣2分/次 |
| 无故缺勤 | 扣3分/次（该次出勤分为0） |
| 连续无故缺勤2次及以上 | 取消评优资格 |

> **保底分说明**：保底 12 分相当于至少出勤 4 次课（50%出勤率），出勤低于 4 次按实际计分。

---

## 5. 课堂表现分（满分 12 / 无保底）

- **规则**：每组在整个课程期间最多获得 **12 次**加分，**每次 1 分**，按实际表现累计。
- **加分条件**（符合任一即可获得 1 次加分）：

| 加分项 | 说明 |
| :--- | :--- |
| ✅ 主动回答问题 | 回答正确或有价值 |
| ✅ 分享创新观点 | 提出独特见解或经验分享 |
| ✅ 上台展示成果 | 代表小组进行成果展示 |
| ✅ 帮助其他小组 | 主动解答其他组的问题 |
| ✅ 提出有价值的问题 | 提问能引发深入讨论 |
| ✅ 提供额外素材/工具 | 分享有用的工具、网站、模板等 |

- **限制规则**：

| 情形 | 处理 |
| :--- | :-: |
| 同一人连续多次抢答 | 建议轮换组员，每人每天最多2次加分 |
| 回答明显错误/无价值 | 不给予加分 |
| 与前面回答内容重复 | 不给予加分 |
| 干扰课堂秩序 | 每次扣1分（从课堂表现分中扣除） |

> **扣分规则**：课堂表现分仅做加分累加，不设扣分起点。但如有干扰课堂秩序行为，从已获得的课堂表现分中扣减。

---

## 6. 综合展示分（满分 16 / 保底 8）

- **评分内容**：最终成果汇报（第4天下午），从 **4 个维度** 综合评分。
- **评分维度**：

| 维度 | 满分 | 评分要点 |
| :--- | :-: | :-: |
| A. AI应用深度 | 5 | Prompt工程能力、工具组合应用、AI产物可用性 |
| B. DevOps全流程 | 4 | 流程覆盖度、工程化水平、各环节衔接 |
| C. 业务价值与创新 | 4 | 痛点解决与量化效果、行业场景创新性 |
| D. 展示与表达 | 3 | PPT制作质量、团队协作表现、现场演讲效果 |
| **合计** | **16** | |

- **各维度评分细则**：

| 维度 | 分值 | 优秀（满分） | 良好（~80%） | 保底（~50%） |
| :--- | :-: | :-: | :-: | :-: |
| A. AI应用深度 | 5 | 多层Prompt优化、多工具组合、AI产物可直接使用 | 使用Prompt、有工具组合意识 | 使用了AI工具 |
| B. DevOps全流程 | 4 | 覆盖4+环节、工程化程度高、有CI/CD配置 | 覆盖3个环节、流程清晰 | 覆盖2个环节 |
| C. 业务价值与创新 | 4 | 有量化数据支撑、痛点解决到位、有行业创新 | 有业务价值、痛点分析合理 | 场景基本匹配 |
| D. 展示与表达 | 3 | PPT精美、全员参与、表达流畅有感染力 | PPT整洁、表达清晰 | 有PPT、表达基本清楚 |

- **扣分规则**：

| 情形 | 扣分 |
| :--- | :-: |
| 未参加最终展示 | 0 分（全组） |
| 仅1人上台展示 | 扣1分（D维度扣减） |
| 超时（超过规定时长） | 扣1分 |
| PPT内容与演练内容脱节 | 扣1分 |
| 演示过程中出现严重技术故障且无法解决 | 扣1分 |

## 附：计分操作说明

- **小组数量**：可切换 4~8 组，切换后重新初始化表格
- **分值编辑**：每个分数格可直接编辑，自动重新计算总分与排名
- **重置分数**：按"重置所有分数"后，各项恢复为保底分值
- **保存/加载**：读写浏览器 `localStorage`（键名：`devops_competition_scores`）
- **排行榜**：根据总分实时排序，前三名显示金/银/铜牌样式
