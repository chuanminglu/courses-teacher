① Core Knowledge
核心知识体系与最佳实践
企业级项目管理体系：组织环境 → 公司战略 → 项目群 → 项目 → 交付物，基于 ISO21500 / GB/T 37507-2019
PMO 职能定位：战略对齐、治理规范、方法论推广、跨项目资源协调与知识沉淀
核心概念辨析：产出（有形/无形交付物）→ 成果（引起的变化）→ 收益（可度量的改进）；项目群以收益为导向
推荐实践：P.P.T 原则 / 外"重"内"轻" / 开发用 Scrum · 运维用看板 / 透明·检视·适应三支柱 / TOC价值流映射
B端三大核心角色：项目经理（推进交付）· 产品经理（洞察需求）· 架构师（技术决策），不要以器御心

③ Practice Points
演练知识要点 （本章时间较短，重点演练4个核心场景）
1
项目章程：给定业务背景，AI生成章程草稿（目标 / 范围 / 里程碑 / 预算 / 干系人）
2
WBS任务拆解：Epic → Work Package → Task，附工期估算与责任矩阵（RACI）
3
风险管理：AI生成风险登记册（概率×影响矩阵 + 应对措施 + 风险责任人）
4
项目进度跟踪：基于当前状态生成进度报告，偏差分析 + 纠偏建议

⑤ Anti-Patterns
反模式警示
❌ AI生成的WBS / 工期估算
直接上报，不经人工校验
❌ 进度报告只是"格式化
流水账"，缺乏风险预警
与关键路径分析
❌ 风险登记册一次性生成
后束之高阁，缺乏动态
跟踪与状态更新
❌ 以器御心：熟练使用AI
工具≠管理能力提升，
忽视团队沟通与领导
✅ AI是"管理加速器"，
判断力与领导力
不可被AI替代
KEY INSIGHT
管理的本质是人与人的协作；
AI处理信息，
PM负责信任与决策
