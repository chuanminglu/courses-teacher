① Core Knowledge
核心知识体系与最佳实践
AI原生技术中台架构（8大模块）：AI IDE（Copilot/代码解释）/ 低代码平台（可视化编排+Runtime）/ AI生成应用（Text-to-App）/ 微服务治理（智能网格Istio+AI）/ 数字化运维（ChatOps）/ 模型服务中台（MaaS·RAG·Prompt管理）/ 基础PaaS（AI数据库·向量库·知识图谱）/ DevOps保障（CI/CD · AIOps · LLMOps）
AI驱动低代码开发原理（三段式）：User指令 → AI Copilot（RAG理解+CoT规划+MCP连接）→ Low-Code Platform（DSL Engine / UI Renderer / Workflow）→ 企业级应用
AI编程3种模式对比：辅助模式（行级补全·Tab接受）/ 生成模式（函数/模块级·Chat驱动）/ Agent模式（跨文件·自主规划·工具调用·自我校验）
SDD+CDD+TDD三位一体：规格驱动（Spec）→ 注释驱动（Comments）→ 测试驱动（Red→Green→Refactor）；上下文管理（Context Engineering）贯穿始终
GitHub Copilot高级应用：Java/Python/前端多栈实践；自定义Instructions / Skill / Agent配置；Copilot Workspace端到端任务编排

③ Practice Flow TDD开发 → Mock前后端 → Agent模式 → 上下文管理
1
AI驱动的TDD开发：DeepSeek/Copilot生成失败测试（Red）→ 最小实现通过测试（Green）→ AI辅助重构消除坏味道（Refactor）；全流程≤30分钟
2
AI驱动的Mock前后端开发：AI生成OpenAPI契约 → AI生成Mock Server（MSW/Mockoon）→ 前后端并行开发 → 契约验证自动化
3
Agent开发模式实战：多文件跨模块任务编排；Copilot Workspace/Cursor Composer实操；工具调用链（MCP）+ 自我校验循环
4
Context Engineering上下文管理：Spec文档 + 代码规范 + 历史对话压缩；.cursorrules / Copilot Instructions配置；幻觉抑制三闸口技巧

⑤ Anti-Patterns
反模式警示
🧑‍✈️ 核心理念：
AI 永远是 Copilot，
人是主导 · 人负责决策
❌ 无脑复制粘贴：
AI生成代码不理解直接
提交，埋下安全漏洞隐患
❌ 跳过单元测试：
依赖AI生成逻辑，
不写测试 = 技术债累积
⚠️ 上下文污染：
无结构Prompt堆砌导致
AI幻觉频发、方向漂移
⚠️ 过度依赖Agent：
大任务不拆分直接交AI
结果失控·难以回溯审查
KEY INSIGHT
AI写代码，人审架构；
AI跑测试，人定质量标准；
工具越强，判断力越重要
