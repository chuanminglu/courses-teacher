## 二、跑之前：三条必须守住的纪律

| # | 纪律 | 为什么 |
|---|---|---|
| **1** | **必须是全新会话**——新开一个，不要复用任何已有对话 | 会话里只要出现过上一轮的产出（哪怕只是读过），就会污染。已实测：单次阅读同题答案造成 33.9% 的近似重合 |
| **2** | **两个会话在不同模型下跑，且互不串味** | 如果是同一个 Claude Code 实例切模型，**切换前必须 `/clear`**。更稳妥的做法是分别启动两个独立实例 |
| **3** | **不要在中途插话、不要让模型"再改改"** | 一臂只跑一次，产出即定稿。中途追加指令会让两臂的"对话轮数"这个隐藏变量不一致 |

## 五、跑完之后

### 5.1 立刻记录 token（趁会话还在）

打开两个会话的用量统计，把数字填进 `05-token记录表.md`。**必须趁会话还在时记**，关掉就找不到了。

需要记：输入 token、输出 token、模型标识、推理参数（temperature 等）。

### 5.2 交给我

告诉我一句"两臂都跑完了"，我会：
1. 跑 `check.py` 对两臂做自动检查（S1 / T3 / D1 / X1 / Q2–Q5）
2. 人工做语义检查（Q1 清单一致性 / T6 语法断言 / H 隐含规则 / C 交叉一致性）
3. 把两臂产出**去掉署名**，生成盲评件

### 5.3 盲评

拿到去署名的两份产出后，按 `06-盲评表.md` 的六项（P1–P6）逐任务打分。

> ⚠️ **为什么必须你来评**：我是 DeepSeek，B 臂是我同类写的，我自评存在系统性高估。我的评分只能作参考，不能作为判定依据。

## 六、异常情况处理

| 情况 | 处理 |
|---|---|
| **产出文件没生成** | 让会话把内容直接贴回来，你手动存；不要让它"重新生成一遍"（会改变轮数） |
| **模型跑去读了别的文件** | 该臂作废，重跑。这是硬性约束被违反，会污染对比 |
| **产出明显被截断** | 让它"继续输出剩余部分"，继续的部分追加到同一文件即可；这属于一次生成的续写，不算第二轮 |
| **一臂跑完另一臂跑不动** | 先跑完的先存着，不着急。但**两臂之间不要互相看产出** |
| **想中途换模型重跑** | 可以，但两臂要么都重跑，要么都不跑。不能只重跑一臂 |
