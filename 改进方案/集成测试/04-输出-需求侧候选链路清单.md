## 第2部分：必须进集成层的高优先级链路

| 优先级 | 链路 | 来源规则 | 为什么必须进集成层 |
|---|---|---|---|
| ★最高 | 删除规则链路（先完成再删除 → 拒绝） | BR-03 | 业务规则跨了 complete 与 delete 两个操作，是最典型的组合链路；01 文档 §三 明确指出此前曾因未标注跨模块而漏测，导致缺陷一路漏到集成层以下 |
| 高 | 完成 → 事件 → 通知（正向/数量/负向） | BR-02 / BR-06 | 事件是异步接缝，最容易"发了没人接"或"漏发/误发" |
| 高 | 异常链路（不存在 id → 报错） | BR-05 | 跨 Service→异常→Controller 映射，直接影响 API 契约（403/404） |
